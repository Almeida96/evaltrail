EvalTrail checks agent behavior through an HTTP adapter or recorded observations. This first release includes ten deterministic checks, baseline comparisons, and JSON, Markdown, and JUnit reports.

The local demo evaluates five support-agent cases and detects two deliberate regressions: an incorrect citation and a forbidden tool call hidden behind a refusal answer. It uses scripted responses and requires no model key.

Download `evaltrail-0.1.0.zip`, extract it, and run `bin/evaltrail demo --out results/demo` (`bin\evaltrail.bat` on Windows). Java 21 or later is required. `SHA256SUMS` contains the archive checksum.

Reports inspect what the adapter records; they do not enforce agent permissions or verify the semantic accuracy of citations. Each case runs once. See the repository documentation for the adapter contract, comparison exit codes, and limits.
